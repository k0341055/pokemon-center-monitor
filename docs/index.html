目前的 token 沒有 Secrets 權限，無法新增收件人或檢查信箱設定。到 GitHub 編輯 token，把 Secrets 設為 Read and write。

每位通知對象的信箱存在 GitHub Secret RECIPIENT_N（舊設定則是 GMAIL_RECIPIENTS 第 N 個），在瀏覽器加密後才送出，這個頁面和 repo 都只顯示代稱。

運作方式

  • 只通知負責的人：補貨時只寄信給商品所在的通知對象。同一件商品可以同時分給好幾位。
  • 未分配＝不監控：沒有分給任何人的商品會留在商品庫，但不會去官網檢查。
  • 何時生效：每次修改都會直接存進 repo 的 watch_config.json，正在執行的監控大約 1 分鐘內套用。
  • 新增通知對象：按「＋ 新增通知對象」輸入信箱，信箱會在瀏覽器用 GitHub 的公鑰加密，直接存成 Secret RECIPIENT_N。存好之後讀不回來，頁面只顯示代稱；要改就用 ✉ 重新輸入。
  • 公開頁面：任何人都能看到商品清單和代稱，但沒有 token 只能看、不能改。
